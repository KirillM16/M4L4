# Этот чат бот консультант по фильмам. Он имеет несколько функций такие как: показ случайного фильма(в том числе информации о нем), добавление фильма в избранное и удаление его из этого списка. Этот бот подойдет для любителей просмотра фильмов, которые иногда не могут выбрать какой то именно фильм. В боте содержится 1000 фильмов(информация о них: название, год, жанр, рейтинг, краткое описание). Также у каждого фильма в информации о нем есть фото его обложки.
